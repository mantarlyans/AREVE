# ARÉVE — картинки коллекции для Google Flow

14 плиток на странице «Տեսականի» (`site/collection.html`). Все в одном стиле, формат 4:5 (1080×1350).

**Как добавить на сайт.** Сохранить как `site/img/flow/<файл>.jpg` и вписать id в список `FLOW` в `site/collection.html` (например `const FLOW = ['pergola', 'awning'];`). Пока id нет в списке, плитка показывает фото объекта.

## Общий стиль — добавлять к каждому промпту
```
Architectural editorial photograph, vertical 4:5. Quiet luxury outdoor living in Yerevan, Armenia.
Warm late-afternoon sun, long soft shadows, golden hour. Palette: warm graphite #1A1814, travertine #ECE7DF,
stone #E1DAD0, muted bronze #B08A57. Clean modern architecture, beige travertine floor, olive trees.
Eye-level camera, 35mm lens, calm symmetrical composition, product in the centre, generous empty space.
No people, no text, no logos, no watermarks. Photorealistic, natural materials, soft contrast, matte finish.
```
